# SoftRise brand assets

Proposed release-candidate identity: peach sunrise and three mint horizon lines. The owner restored the three-line mark and requested transparency.

- softrise-icon.svg: editable 500-unit icon on navy for store use.
- softrise-logo-transparent.svg / .png: 500px mark with true alpha transparency, no background box.
- softrise-store-500.png: 500×500 opaque RGB with embedded sRGB profile, for the store listing.
- softrise-device-128.png: optional 128×128 device-store asset.
- softrise-wordmark.svg / .png: name plus “A gentler start.” on a transparent background for repository/presentation use. The wordmark SVG uses system font fallbacks; the rendered PNG preserves the inspected appearance.
- resources/drawables/launcher.png: transparent 60px native launcher; launcher.svg retains the editable source.

Palette: navy #101C26, mint #A8DFCA, peach #F5C89E, off-white #F3F6F5. No Garmin brand elements are included. Vector source was refined directly; PNGs are deterministic SVG renders via scripts/render-brand.py, not AI-generated raster artwork.

Garmin’s current store guidance specifies 500×500 sRGB, solid non-black background, no descriptive text, and at least 10px padding. See https://developer.garmin.com/brand-guidelines/connect-iq/. Final approval remains with the owner and Garmin.
